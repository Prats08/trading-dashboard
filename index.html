Connect GitHub to edit

Adding or removing tickers writes to memory/portfolios.json in your repo, which GitHub requires you to authenticate for. Paste a fine-grained personal access token scoped to this repo with Contents: Read and write. Your token is stored only in this browser (localStorage) and is sent directly to api.github.com — never to any third party. Viewing the dashboard needs no token.

Create one at GitHub → Settings → Developer settings → Fine-grained tokens. Limit it to a single repository and to the Contents permission. Set a short expiry.
